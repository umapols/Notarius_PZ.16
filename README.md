# Notarius_PZ.16

## Функциональные возможности:
- Регистрация клиентов 
- Ведение справочника нотариальных услуг
- Оформление свидетельств и удостоверение договоров
- Автоматический расчёт комиссионных
- Формирование и печать документов
- Ведение реестра сделок
- Финансовая отчётность для руководителя

## Сценарии использования:
1. Оформление свидетельства о верности копии
2. Удостоверение договора купли-продажи
3. Формирование отчёта о доходах

## Технологии:
- Язык программирования: C# 
- Интерфейс: Windows Forms
