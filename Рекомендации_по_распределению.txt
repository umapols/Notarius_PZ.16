Рекомендации по распределению дополнительных обязанностей и сделок между нотариусами

1. Не назначать срочные услуги нотариусу, у которого уже есть 3 и более незакрытых дел.
2. При распределении учитывать тип услуги: нотариус должен иметь соответствующую лицензию (например, удостоверение договоров с недвижимостью).
3. Для равномерной нагрузки рекомендуется автоматически переключаться между нотариусами после каждой услуги.
4. Руководитель имеет право вручную переназначить сделку другому нотариусу через административную панель.
5. Все распределения должны логироваться для последующего анализа.
6. При регистрации нового клиента помощник выбирает нотариуса из списка доступных (с учётом загрузки).
7. В случае длительного отсутствия нотариуса (отпуск, больничный) его исключают из очереди распределения.
